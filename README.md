# Creative Studio

Creative Studio is a local-first React code viewer backed by a Node.js Bridge.

## Run Locally

```bash
pnpm install
pnpm dev
```

Open <http://127.0.0.1:5173/>. The Bridge runs at
<http://127.0.0.1:8787/> and uses the host operating system's directory selector.

The first version is read-only and supports workspace browsing, open document tabs,
syntax-aware code viewing, and workspace/file search.
